# CS 61: Systems Programming and Machine Organization

**Harvard, Fall 2025.** How software runs on real hardware: C/C++, memory allocation, x86-64 assembly, operating system kernels and virtual memory, caching and I/O, processes and shells, and multithreading.

This repo has my problem sets **pset0–pset6** with their full commit history. Each pset starts from the course's handout code, and my commits complete it: a debugging memory allocator, a binary bomb, the WeensyOS kernel, buffered I/O, a Unix shell, and a synchronized multithreaded program.
